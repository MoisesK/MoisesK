## 👋 Quem sou

**Moisés Kalebe de Medeiros Farias** — CEO e Fundador da [**MK Solutions**](https://mksolution.com.br/) e Tech Leader na
[@HeadersConsultoria](https://github.com/HeadersConsultoria). São **8+ anos** construindo software para empresas
de diferentes setores, do desenho da arquitetura até a hospedagem e o monitoramento em produção.

Meu trabalho vive na interseção entre **engenharia e negócio**: arquitetura bem pensada, código limpo e testado,
e decisões técnicas que se traduzem em resultado real para o cliente.

- 🏗️ **Arquitetura & Backend** — Laravel, Slim, Fastify, mensageria com RabbitMQ, cache com Redis
- 🚀 **Produto ponta a ponta** — monorepos pnpm com API, web (Next.js), workers e apps mobile
- ☁️ **Infra & DevOps** — Docker, Nginx, GitHub Actions, deploy automatizado e monitoramento
- 📦 **Open Source** — mantenedor de SDKs e pacotes PHP na [AstrotechLabs](https://github.com/AstrotechLabs)
- 🧭 **Liderança técnica** — code review, padronização, metodologia ágil e mentoria de devs
- 📈 **+1.000 contribuições** no último ano · **70 repositórios**
